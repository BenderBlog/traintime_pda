# 被禁止的设计

## 路由

* 不把命名路由设为所有 feature 的默认要求。需要在 Master-Detail View 中展示的页面由所属 feature 构建，通过 `AppShell` 的方法在详情路由栈中导航。
* 不通过引用其他 feature 的路由常量实现跨模块导航。跨模块接线由启动装配或消费方 `ports` 承担。
* 不用全局 `Navigator` 键或静态路由名判断详情导航目标和状态。`AppShell` 持有详情导航状态，调用方明确选择详情导航或根路由。
* 路由名无法解析时不返回空页面。应明确报错，避免把导航错误伪装成正常页面。

# 账号与生命周期

* 不把账号密码、会话令牌等敏感凭据写入 `shared_preferences` 或其他普通偏好存储。使用适合凭据的安全存储。
* 不以首页 Widget 的 `initState`、`didChangeDependencies` 等生命周期作为账号级登录刷新或提醒初始化的唯一触发入口。由启动装配或所属功能管理这些任务。
