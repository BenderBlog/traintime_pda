# Apple Watch 代码审计记录

日期：2026-09-07。

本轮按同步链路、缓存安装、共享业务规则和多语言资源进行源码审计与重构。
保留界面布局、字体、颜色、手势参数和现有日志。没有执行编译、测试脚本或模拟器验证；
下方列出已补充的用例与交给使用者执行的验证步骤。

## 范围

- `watchOS/Models`、`Connectivity`、`Storage`、`Shared`：模型、协议、状态、缓存。
- `watchOS/Views`、`Widget`：检查业务函数和本地化调用，不调整视觉布局与交互参数。
- `ios/Runner/WatchConnectivityManager.swift` 与 `PhoneWatchQueuedScheduleTransport.swift`：
  配对手机的原生同步链路。
- `lib/repository/watch`：完整学期展开和响应式同步服务。
- String Catalog、相关回归源码和三个 target 的共享文件编译成员。

月份预热、分页、表冠与新手引导已经有专用共享实现，本轮保留这些界面基础设施。

## 修复与合并

| 问题 | 本轮处理 |
| --- | --- |
| `installProgressiveSnapshot` 拒绝旧数据后，调用方仍返回成功，完整学期流程可能写入错误版本号 | 安装入口返回真实结果；只有成功安装才确认学期版本，失败保留已有课表与版本 |
| 学期分块只按课程 ID 累积，缺少独立的元数据一致性校验 | `WatchSemesterTransfer` 集中处理累积、元数据比较、排序与复位；旧协议无版本号时也拒绝混合分块 |
| 非末页的偏移量不前进时会重复请求相同分页 | 共享分页检查拒绝不前进的偏移和不完整的当天/14 天快照，提供三语言错误提示 |
| 手机验证、版本计算和每个分页分别解析整份 JSON | 输入只解析一次并缓存完整文档；范围筛选和分页复用只读文档，版本计算使用同一根对象 |
| 同内容重试时可能发布生成时间不同于已保存正文的快照 | 重试发布当前保存的正文，使 Application Context 和分页保持同一份元数据 |
| 手机、手表和后台队列分别声明协议键与语言映射 | 移至纯 Foundation 的 `WatchSyncSupport.swift`，三个 target 共用相同定义 |
| App 与 Widget 各自维护 schema 校验 | 统一经过 `WatchScheduleCoding.decode`，支持范围保持 1–4 |
| 标准缓存与 App Group 相同内容被重复解码，同一次索引安装又重复合并课表 | 相同正文先去重解码；索引复用本次安装的合并结果，清空和恢复时显式更新该结果 |
| 时间戳转换、24 小时文本、位置/教师摘要和课程排序有重复实现 | 统一到 `WatchScheduleDate`、`WatchScheduleText`、`WatchCourse.locationSummary` 与共享排序入口 |
| 派生缓存分别创建不可关联取消的后台编码任务 | 使用 `WatchCacheCoding.encodeInBackground`，父任务取消会传递给后台任务；原有代次、签名与交互暂停校验继续生效 |
| 刷新与启动等待的旧超时任务只能等到时间结束 | 分别保存任务句柄，新一轮刷新、回复和清空时取消对应任务 |
| 今日统计重复过滤同一批课程，考试和实验分别扫描 | 复用已计算的当日课程，分类计数改为一次遍历 |
| 完整学期展开反复解析时间表并扫描所有星期的安排 | 标准节次分钟值只解析一次，学校安排先按星期建立索引 |
| 用固定 24 小时计算自然日和周次，夏令时地区可能错位 | 自然日通过年月日运算，周次通过日历日期差计算 |
| 缺少范围字段的旧缓存依赖课程数组的首尾顺序 | 使用真正的最早开始和最晚结束时间恢复范围 |

原始快照 schema、通信键值、App Group 键名和旧小组件链接的兼容行为保持不变。
工程文件仅新增共享源码成员，没有改变本轮开始时的签名与部署配置。

## 多语言

继续支持简体中文、繁体中文和英语，不翻译学校提供的课程、教师或地点原文。

1. 语言同步从课表同步中独立出来。退出登录、清空课表或暂时没有学期数据时，
   语言仍可同步；切换语言不会重新展开完整学期。
2. 语言写入与课表写入共用串行队列，实际发送前去重，保留快速 A→B→A 的最终选择。
3. `zh-Hans`、`zh-Hant` 脚本标识优先于地区，兼容下划线、短横线、香港、澳门和英语地区码。
4. 文案读取与格式化参数统一使用手机指定 Locale；资源包缓存不保存旧语言的最终文本。
5. 补齐“关闭课表过期提示”、考试“座位 %@”、无效分页提示和小组件示例课程的翻译。
6. 考试座位前缀在显示层本地化，原始 `note` 和课表语义版本不因语言切换改变。
7. 英语数量文案改用指标标签，兼容 0、1 和多个项目；修正“即将上课”等状态翻译。
8. 207 个资源键中，4 个空串/数字/分隔符标记为无需翻译，其余资源保留简体源文案及繁体、英语实现。

页面文件只替换重复的数据处理或本地化调用；现有 SwiftUI 样式修饰符与交互参数未调整。

## 日志保留

保留 iPhone 的 `[WatchConnectivity]` 日志入口及原有各调用点，包括激活失败、
非法 JSON、相同内容跳过发布、语言更新失败和上下文发布失败。

保留 `[WatchScheduleStore]` 的解码、学期合并、派生缓存编码等诊断入口，以及
`[WatchScheduleSyncService]` 的同步成功数量、语言发送失败、清空失败和同步失败日志。
原有 `Unsupported schedule schema: …` 诊断文本迁入共享数据错误类型后仍保持原样。
没有清理日志、降低日志级别或删除历史本地化键。
